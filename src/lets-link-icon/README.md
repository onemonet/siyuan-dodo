# 链接图标

链接图标子模块支持外链图标，以及显式开启的 Open Graph 链接卡片。

## Open Graph 链接卡片

为段落块设置以下自定义属性即可开启：

```text
custom-dodo-og-card="true"
```

只有同时满足以下条件时才会渲染卡片：

- 块类型为段落块；
- 块内只有一个 `http` 或 `https` 链接；
- 该链接是块内唯一有效内容。

未设置属性或不满足条件时，不会请求目标网页，也不会改变原链接显示。

也可以在块菜单或链接右键菜单中选择“启用链接卡片”或“关闭链接卡片”，菜单会自动添加或移除该属性。

卡片不使用单独的缓存索引文件或缓存有效期。普通加载和重载时，卡片只读取思源原生块和链接数据：链接锚文本作为标题，链接的 `data-title`（或 `title`）作为简介，块属性 `custom-data-assets-og-card` 作为本地图片路径，因此不会因为渲染卡片而请求目标网页。

首次通过菜单启用卡片时，会先按规范化链接 URL 的 SHA-256 哈希查找 `assets/dodo/link-icon/` 下的本地图片；命中时直接复用，不请求网页。没有命中时才重新获取网页信息。点击卡片右上角的刷新按钮会跳过本地查找并强制重新获取。获取成功后，网页标题会写入链接锚文本，网页简介会写入原生链接标题（`data-title`），已有值在刷新时会被覆盖；新图片会使用 `og-card-<SHA-256>.<扩展名>` 命名并下载到工作空间的 `data/assets/dodo/link-icon/`，然后把思源返回的实际 `assets/dodo/link-icon/...` 路径写入块属性 `custom-data-assets-og-card`。图片下载失败时会保留原有本地图片。

关闭卡片时会移除运行时卡片标记并清除图片属性，之后可由思源原生的未引用资源清理回收图片；如果资源仍在工作空间中，再次启用同一链接时会优先命中这张本地图。卡片标题左侧直接复用普通链接图标规则中 `/public/custom-link-icons/` 下的本地图标，不新增卡片图标属性，也不会下载或请求网页 favicon；没有匹配的本地图标时不显示左侧图标。
