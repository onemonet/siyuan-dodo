## 使用方法

### 1. 启用插件

在工具箱插件设置中，找到 "Flomo 同步" 模块并启用。

### 2. 配置账号

配置以下必填项：
- **账号**: Flomo 手机号或邮箱
- **密码**: Flomo 密码

插件会自动获取 AccessToken。

### 3. 配置同步选项

可选配置：
- **内容模板**: 自定义同步格式
- **同步方案**: 选择 DailyNote 或指定文档
- **标签过滤**: 设置包含或排除的标签
- **回写标签**: 标记已同步的 memo

### 4. 同步数据

点击工具箱菜单中的 "同步 Flomo" 即可开始同步。
