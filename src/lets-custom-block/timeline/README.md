# 时间线预览 (timeline)

把 Markdown 表格转换成 TimelineJS3 时间线预览块。来源表格每行一条事件，各列通过**表头**映射到事件字段；识别不到的列可在时间线块 ⚙ 设置面板「字段映射」中手动指定。

> 字段定义的单一权威出处：[services/field-mapping.ts](services/field-mapping.ts) 的 `TIMELINE_FIELD_DEFINITIONS`。改字段支持时先改那里，再同步本表。

## 支持字段

| 字段 | 必需 | 自动识别表头（归一化后全等） | 列序兜底 | 单元格格式 |
|------|------|------------------------------|----------|------------|
| 标题 title | 推荐 | `title` `标题` `事件` `名称` | 第 1 列 | 纯文本 |
| 开始时间 startDate | ✅ 必需 | `startdate` `date` `开始日期` `开始时间` `日期` | 第 2 列 | 日期，见下方「日期格式」 |
| 结束时间 endDate | 可选 | `enddate` `end` `结束日期` `结束时间` | 第 3 列（表格 ≥3 列时） | 同上；与开始时间组成时间段事件 |
| 显示日期 displayDate | 可选 | `displaydate` `显示日期` | 无 | 数据库只能绑定文本列；如 `2026 年秋季`，仅覆盖展示文字，不影响时间轴排序 |
| 说明 description | 可选 | `description` `desc` `text` `说明` `描述` `内容` | 第 4 列（表格 ≥4 列时） | 纯文本，支持换行 |
| 分组 group | 可选 | `group` `分组` | 无 | 纯文本；同组事件显示在同一行 |
| 媒体 media | 可选 | `media` `媒体` | 无 | Markdown 图片、`<img>` 标签或纯资源路径 / URL，多图取第一张，见下方「媒体格式」 |
| 媒体说明 mediaCaption | 可选 | `mediacaption` `媒体说明` `媒体标题` | 无 | 文本说明，随媒体显示 |
| 背景颜色 backgroundColor | 可选 | `backgroundcolor` `背景颜色` `背景色` | 无 | CSS 颜色值：HEX（`#FF5733`）或 `rgba(...)` |

## 识别规则

1. **⚙ 字段映射手动指定**（设置面板精确表头匹配）→ 2. **表头别名** → 3. **列序兜底**。
   分组、显示日期、媒体、背景颜色四个扩展字段**没有列序兜底**——表头对不上时必须手动映射，否则该字段留空。
2. 归一化规则：表头去空白与 `_` `-` `:` `/` 后转小写再做全等比较，因此 `Start Date` ≙ `start_date` ≙ `startdate`。
3. 别名单刻意保持精简，避免同义词之间的歧义；不常见的表头请走 ⚙ 字段映射手动指定。
4. 表格至少 2 列；没有任何一行能解析出开始时间时报「没有找到有效的日期值」，该行日期无效则跳过该行。
5. 识别结果在建块时写入 `fieldMapping` 配置；之后来源表格只影响数据，不影响已保存的映射。

## 日期格式

- `2024`（仅年）、`2024-01`（年月）、`2024-01-01`、`2024-01-01 15:30:45`（含时间）
- 兼容中文写法：`2024年1月1日`
- 分隔符 `/`、`.` 与 `-` 等价（`2024/1/1`）
- 结束时间列解析失败不影响事件，仅按开始时间显示

## 媒体格式

- Markdown 图片：`![说明](assets/xxx.png)`，alt 文本作为媒体说明
- `<img src="assets/xxx.png" alt="说明">`
- 纯资源路径或 URL：`assets/xxx.png`、`https://example.com/a.png`
- `assets/` 开头的路径会自动锚定到站点根目录（iframe 内相对路径会指错位置）
- 图片类型（png/jpg/gif/webp/svg 等）会同时作为时间轴 marker 缩略图；视频、音频等按 TimelineJS3 规则嵌入幻灯片

## 数据库来源

来源块也可以是思源数据库块（属性视图）：

- 列 = 数据库在**当前视图**中显示的字段（字段名即表头），视图的过滤与排序在渲染时生效；
- 字段映射的下拉框会列出字段名，识别规则与表格来源一致（别名 → 手动映射；数据库字段**没有列序兜底**）；
- **date 字段**：自动识别为开始时间；单元格勾选了结束日期时，适配器会追加虚拟列 `结束时间`（重名时为 `<字段名>·结束`），自动命中结束时间别名——时间段事件零配置；日期值为内核 UTC 毫秒时间戳，按 UTC 格式化，与思源显示一致；
- **字段类型转换**：单选/多选 → 选项文本、资源 → Markdown 图片（供媒体列消费）、关联/汇总 → 内容拼接、复选框 → `true` / `false`、数字 → 显示串；
- 字段映射支持桌面数据库挂件那套常见命名（headline / date / display_date / group / media / background_color 等，归一化后全等）；
- 绑定时自动从块 DOM 解析 avID 写入配置（`sourceType: "database"`），刷新时免重复探测；变更检测对适配结果做哈希，内容未变化不产生写入。

## 使用方式

- 创建：右键表格块 / 数据库块 → 「插入时间线预览块」，或在表格 / 数据库块后一行输入 `/dodo时间线`
- 设置：悬停时间线块点 ⚙（来源块绑定 / 折叠源块 / 外观 / 字段映射）
- 刷新：来源表格变更约 1 秒内自动重新加载；内容未变化时不会产生写入
- 未绑定来源时，时间线卡片内可一键「创建示例表格并绑定」

### 数据库时间线设置自动保存（2026-10-18）

数据库时间线与数据库图表的设置交互一致：修改字段映射、预览高度、时间线占比、开始位置后等待约 300ms 自动保存到当前视图配置 `VISUAL_ATTR`，成功后更新 iframe 高度并刷新 TimelineJS3；不再显示手动「保存设置」按钮。独立时间线块仍保持自身原有的自动应用配置方式。共享 Svelte 4 设置 UI 使用 `ui/debounced-settings-saver.ts` 串行合并配置写入：不会因连续请求让旧修改在新修改之后覆盖配置；关闭弹窗立即提交待保存修改；校验/网络错误明确提示并允许后续修改触发重试；点击「刷新时间线」会先等待配置保存成功。`npm run test:timeline-autosave` 验证防抖、串行、失败恢复与关闭保存。Chrome 使用真实 Svelte 时间线面板及模拟思源设置接口实测了字段「不使用」、占比连续更改、保存失败恢复、关闭即保存和预览刷新，没有 JS 报错。

### 思源日期列区间识别（2026-10-18）

数据库日期列的原生 `date.content` 为开始时间，`date.content2` 为可选结束时间；仅 `hasEndDate && isNotEmpty2` 时结束时间有效。若时间线「开始时间」与「结束时间」都绑定**同一个日期列的真实 keyID**，TimelineJS3 事件取这个日期列的开始值和结束值，日期范围会显示为持续事件。单日数据、没有开启结束时间或结束值为空时，事件仅有开始日期，不重复使用开始值作为结束值。若两个映射绑定**不同的数据库日期列**，继续分别取各列本身的开始值，兼容以前的规则。独立 Markdown 表格时间线不变。

日期区间直接复用 `av-data-adapter.ts` 已提供的内部 `dateKeyID:end` 结束日期列，不改真实数据库，也不修改保存的 `fieldMapping` keyID。`TimelineTransformerService` 仅在数据库模式检测到起止映射解析到同一列时，按该列原生 `content2` 虚拟结束列取值；缺失虚拟列时表示没有结束时间。`npm run test:timeline-date-range` 以真实 AV 响应结构回归单日、日期范围、禁用结束时间、不同列、带时分、日期排序、列改名和 Markdown 兼容。

### 时间线媒体字段简化（2026-10-18）

仅保留「媒体」及「媒体说明」映射，已移除「媒体来源」「媒体缩略图」两项和关联的事件字段覆盖逻辑。旧配置如果保存过 `mediaCredit` 或 `mediaThumbnail`，不再读取、不会误绑定；原图片媒体仍自动用自身的 URL 作为缩略图 (`thumb` / `thumbnail`)，无需额外设置。

### 时间线字段简短说明（2026-10-18）

设置面板「字段映射」的每个字段名右侧新增信息按钮，悬浮即可显示该字段的简短功能说明；来源/外观设置亦有相同提示。使用公共 `FieldHelp.svelte` 与思源主题配色；Tooltip 在页面 `body` 层悬浮定位，不受时间线设置滚动区域裁切，并在屏幕边缘自动换向。信息按钮与字段文字垂直居中，提示不影响字段绑定或自动保存。面板底部的使用说明已缩短。
