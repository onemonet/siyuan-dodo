# 图表块（chart）

自定义块系统的第三种块类型：在表格块 / 数据库块旁插入**独立的图表块**，图表通过来源属性引用来源块，数据与视图分离——来源保持普通内容块，图表只是它的视图。

图表块本体是思源原生 ```echarts 代码块，携带以下块属性：

| 属性 | 说明 |
| --- | --- |
| `custom-dodo-block="chart"` | 类型标记（反射到 DOM，供 ⚙ 按钮注入与自动刷新索引使用） |
| `custom-dodo-chart-source` | 来源块 ID（表格块或数据库块），创建时默认为上方块 |
| `custom-dodo-chart-config` | 图表设置 JSON：含图表类型 type、来源类型 sourceType（table / database）及轴映射 / 聚合 / 参考线 / 风格等全部设置 |

设计评估见 [docs/plans/2026-09-05-chart-custom-block-assessment.md](../../../docs/plans/2026-09-05-chart-custom-block-assessment.md)。

## 使用方式

1. 右键表格块 / 数据库块图标 → **插入图表块**：在来源块下方插入图表块，自动绑定来源并根据默认图表类型生成图表。
2. **斜杠快捷创建**（默认开启）：在表格块或数据库块后一行输入 `/dodo图表`（菜单名称与触发词可在设置的色卡卡片中自定义，支持多个触发词与多行菜单项），回车选中「插入图表块」即可在光标处快速创建图表块；来源取光标所在块或其上一行的表格块 / 数据库块。
3. 悬停图表块 → 右上角图标条最前方的 **⚙ 图表设置** 按钮（图表块右键菜单已移除，⚙ 是唯一入口）：在 ⚙ 旁弹出悬浮设置面板，无遮罩、可继续编辑文档；右侧空间不足时自动左移。再次点击同一块的 ⚙ 关闭面板，点击其他图表块的 ⚙ 切换目标。面板顶部提供「折叠源块」开关：开启折叠来源表格（只看图表），状态与块的折叠属性实时同步。
4. 面板内能力一览：图表类型按钮行（柱状/条形/折线/面积/饼图）+「更多」二级列表（平滑折线/堆叠折线/堆叠面积/散点/漏斗/雷达）、X 轴与 Y 轴设置、风格色卡，底部「刷新图表」手动重算。
5. **自动刷新**：默认开启（设置项"来源表格变更时自动刷新图表"）。编辑来源表格（含多设备同步进来的变更）后约 1 秒自动重新生成图表；打开文档时也会静默校正陈旧图表。防抖合并连续编辑；内容未变化时跳过写入，不产生多余的撤销记录与同步流量。
6. 来源表格被删除时，图表保留最后一次生成的内容，手动刷新会提示来源不可用。

## 图表设置说明

所有设置持久化在图表块属性 `custom-dodo-chart-config`（JSON）中：

| 设置项 | 取值 | 说明 |
| --- | --- | --- |
| 图表类型 | 柱状图 / 条形图 / 折线图 / 面积图 / 饼图 + 更多（平滑折线 / 堆叠折线 / 堆叠面积 / 散点 / 漏斗 / 雷达） | 保存于 config 的 type 字段 |
| X 轴·显示内容 | 来源表格的列名 | 分类轴取哪一列，默认第一列 |
| X 轴·排序方式 | 默认顺序 / 总数大→小 / 小→大 / 按名称 | 按聚合后的数值或名称排序类别 |
| X 轴·忽略零值 | 开关 | 过滤所有系列聚合后均为 0 的类别 |
| Y 轴·显示内容 | 总数 / 平均 / 最大 / 最小 | 同名类别的多行取值方式（聚合） |
| Y 轴·分组方式 | 无 / 某列名 | 透视模式：该列去重值作为系列，取第一个数值列作值 |
| Y 轴·范围 | 自动 / 自定义 min~max | 值轴固定范围，条形图作用在数值轴上 |
| Y 轴·参考线 | 数值 + 可选名称 | 虚线 markLine，横跨绘图区 |
| 风格·颜色 | 自动 / 彩色 / 黑白 / 蓝 / 黄 / 绿 / 紫 / 蓝绿 / 橙 / 粉 / 红 | 色卡式选择；单色系为同色相由深到浅的阶梯 |

## 表格结构要求

### 柱状图 / 折线图 / 面积图 / 条形图

```md
| 类别 | 系列1 | 系列2 |
| ---- | ----- | ----- |
| A    | 10    | 20    |
| B    | 30    | 40    |
```

### 饼图 / 漏斗图

```md
| 分类 | 数值 |
| ---- | ---- |
| A    | 10   |
| B    | 20   |
```

### 散点图

```md
| X值 | Y值 | 系列 |
| --- | --- | ---- |
| 10  | 20  | A组  |
| 15  | 30  | B组  |
```

### 雷达图

```md
| 系列  | 维度1 | 维度2 | 维度3 |
| ----- | ----- | ----- | ----- |
| 方案A | 80    | 70    | 90    |
| 方案B | 60    | 85    | 75    |
```

## 数据库来源

来源块也可以是思源数据库块（属性视图）：

- 列 = 数据库在**当前视图**中显示的字段（字段名即表头），视图的过滤与排序在渲染时生效；
- 字段类型自动转换：数字 → 数值（直接标记数值列，无需正则探测）、单选/多选 → 选项文本、资源 → Markdown 图片、关联/汇总 → 内容拼接、复选框 → `true` / `false`；
- 绑定时自动从块 DOM 解析 avID 写入 config（`sourceType: "database"`），刷新时免重复探测；
- 自动刷新同样适用：数据库块内编辑（含同步进来的变更）会触发块 DOM 变化，约 1 秒内自动重新生成。

## 说明

- 渲染使用思源原生 echarts 代码块管线，编辑、只读、移动端表现一致。
- 历史版本曾以独立模块提供"表格与 chart 块原地互转"（`custom-chart-backup` 属性备份），该功能已移除；旧文档中的备份属性不再被使用，可手动清理。
