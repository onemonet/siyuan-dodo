# Frappe Gantt — 思源数据库甘特视图

## 架构
- Frappe Gantt 1.2.2 (MIT)，全部 JS、CSS 和原始 LICENSE 在 iframe 内本地打包。无 CDN、无 DHTMLX 运行时。
- 主插件通过思源 /api/av/renderAttributeView 读取原生 AV 当前 viewID 数据。
- 原生字段 keyID 映射、进度比例、颜色和分组继续使用原有 gantt-model.ts。
- 时间日期、进度写回仍复用 gantt-write.ts 经 /api/av/setAttributeViewBlockAttr 完成，iframe 只能发送 postMessage。
- 显示与数据分离：时间轴由 Frappe SVG 实现，左侧三列表格由原生 DOM 实现。项目组可折叠，配置在统一视图 JSON 存储，不存任务副本。
- 视图随可见任务自动撑高，由父页面直接观察 iframe 内容尺寸，不依赖子脚本的高度消息，也不以 0 高度初始化，因此旧缓存或原生视图头部暂时重建不会隐藏内容。折叠分组、清空任务和窗口宽度变化时同步高度；日期轴保留横向滚动。左侧任务表可折叠，让时间轴展开到全宽；两端悬浮日期分别显示在任务条左侧和右侧，与任务条垂直居中同行。
- 小时/日刻度按 15 分钟吸附，设置页也支持 30 分钟；周/月按 1 天吸附。
- Frappe 1.2.2 的 snap_at 传入 "900s"/"1800s" 避免 "15min" 被 parse_duration 正则误识别为月份。
- 日期转换集中于 gantt-date-codec.ts：与思源原生日期编辑器一致，按本地时区读取和写入 content/content2 时间戳，不把界面的时分当作 UTC。前端协议只允许 YYYY-MM-DD 或 YYYY-MM-DD HH:mm；API 日期字段最终一律写入 :00.000，保留 isNotTime 和单列日期范围结构。按天移动保留本地时分，跨夏令时的嵌套日期范围按日历分钟平移。
- 思源原生界面能编辑到分钟而不是秒，旧记录若存在非零秒或毫秒，读取可精确显示到分钟，仅在用户操作修改后对被写字段归零；不主动清洗未修改的数据库数据。
- SiYuan 甘特模型端点是排他 end_date，Frappe 在午夜整点可能自动增加 1 天，因此渲染器私有的末端用 1ms 哨兵阻止隐式增天。1ms 只用于 SVG 几何计算，不能进入 SiYuan API；保存仍使用 _end 原始 Date，经 codec 后输出整分钟时间戳。
- Frappe on_date_change 在拖动过程中可能反复触发；先缓冲最终日期，再在 SVG mouseup 后仅发送一次原生 API 写入。保存后重新读取思源数据；数据结构不变时只调用 update_task 刷新修改过的条形，不重建整个 SVG。
- 只有任务数量、排序、分组折叠、时间刻度改变或任务移出当前时间轴范围时，才重新生成 SVG 内容，继续复用同一实例和 SVG 元素。
- 双击任务仍可使用思源原生数据库字段写回弹窗。含异常日期或未映射字段不会误写。
- 旧版本的 viewID 字段映射与配置保持可读，不需要重建数据库。

## 验证
- 采用模拟思源 AV 数据与注入 writer 测试读取、写入、日期结束区间、时分、冲突和回滚；真实笔记只可做只读 API 检查。
- 浏览器测试使用真实 Frappe Gantt UMD，而不是伪造 API，验证 15/30 分钟精度、拖动消息、仅保存一次、回读后局部更新和本机页面渲染。
- `node scripts/test-database-gantt-timezone.mjs` 检查东八区 00:00/06:00 的实际写回值及回读，并覆盖 UTC、纽约、印度时区和夏令时；使用带明确时区偏移的测试时间戳，避免把同一处 UTC 假设同时写进实现和测试。
