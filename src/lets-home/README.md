# 主页

主页是一个可持久化的个人工作台框架，右键画布打开组件目录。组件按以下五类组织：

- 笔记数据：最近文档、收藏文档、任务、快速笔记、子文档、条件文档、复习文档、便签、强化日记
- 可视化：热力图、SQL 查询、可视化图表、统计卡片
- 日常工具：高级番茄钟、全局日历、习惯打卡、纪念日、天气、时钟、音乐、图片轮播、记账
- 信息资讯：热搜、每日一言、新闻资讯、星座运势、历史上的今天
- 自定义：文档编辑器、文字内容、网页浏览器

未实现的组件会以灰色禁用状态显示。布局位置、尺寸和组件实例使用 GridStack 网格坐标保存；同一组件类型预留独立实例 ID，允许未来按不同配置重复添加。旧版布局仍可读取。
