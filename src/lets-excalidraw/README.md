# Excalidraw
## 上游依赖（开发预览版）

当前使用上游 `@excalidraw/excalidraw@0.18.0-3c916c5`，对应 npm 的 `next` 开发预览版本，已在 `package.json` 和 `pnpm-lock.yaml` 中固定。
此版本不属于稳定发行版。其 SVG/PNG 导出统一使用 `exportScene`，由 `app/excalidraw-export.ts` 适配已有保存流程；元素版本更新和原生连线 API 也有变化。
运行 `pnpm test:excalidraw` 和 `pnpm build` 验证代码兼容性。正式使用前请在测试工作空间手动确认画布打开、编辑、保存、导出、思源块嵌入和回退。


在工具箱设置的「开关」中启用 Excalidraw。启用前先停用独立的 `siyuan-dodo-excalidraw` 插件。使用 `/excalidraw` 或思源快捷键设置中的「创建 Excalidraw 图像」创建画布，也可通过旧画布图片上的编辑按钮或图片菜单打开。

模块默认关闭。首次启用会导入旧插件配置，并在目标素材库不存在时复制旧素材库；旧文件不删除。SVG/PNG 附件及笔记引用保持原位。旧插件的自定义快捷键需要重新绑定。

悬浮工具栏默认跟随选区，拖动左侧手柄可固定位置。「更多 → 恢复跟随选区」可解除固定。「更多 → 自定义工具栏」可设置固定工具、顺序和文字标签；未固定工具仍在更多菜单中。工具栏关闭或没有选区时，可从画布原生主菜单的「画布增强设置」找回，也可在工具箱设置中打开工具栏开关。

当前接入「缩放至选区」、「对齐」（左、水平居中、右、顶、垂直居中、底六项）和「排列」（横向、纵向、分类、自动排列，以及水平/垂直等距分布）。水平和垂直等距分布仅在「排列」菜单中选中三个或更多元素时显示。对齐会一并更新绑定文字、箭头端点并提交为一次撤销记录。新工具支持直接按钮、操作分组与参数面板三种形式，后续逐项迁移。交互增强独立于工具栏启停，已接入的交互模块会在增强设置中显示开关。旧 `excalidraw-v2` 加载片段不再注入此插件画布，防止重复工具栏与监听；原脚本和配置文件保留，其他自定义片段仍可使用。

在思源内打开 Excalidraw 后，先在画布空白区域单击，再按 @ 打开思源块搜索框，输入关键词并通过方向键、回车或鼠标选择结果，可在画布点击位置插入可刷新预览的思源块。Esc 取消。此功能默认为启用，位于「画布增强设置 → 其他设置 → @ 搜索并插入思源块」；在文本编辑框中输入 @ 不会劫持正常文本。链接输入框中的 @、[[、【【 仍用于创建 siyuan://blocks/ 链接，和画布直接插入是不同操作。 搜索结果展示原生块类型图标、关键词高亮、所属路径和引用次数。现在使用思源原生「块引用搜索」内核接口 `/api/search/searchRefBlock`，保留内核排序（文档/块的匹配优先级及引用历史）；搜索类型直接遵循思源内核的「搜索设置 → 块类型」，而 `@`、`[[` 和 `【【` 均以原生方括号引用模式查询，受「方括号仅搜索文档」设置控制。

标签显示、格式、编辑窗口、主题、自动保存及代码片段在工具箱的 Excalidraw 设置页配置。自动保存间隔与主题等编辑器参数在重新打开画布后生效。「保存并关闭」和模块停用会等待保存确认；保存失败时保留编辑窗口。通过原生标签/窗口关闭的未保存场景会暂存在当前浏览器，重新打开同一附件时恢复，请及时保存。

原生 Agent 能力继续使用 `dodo-excalidraw.read_me` 和 `dodo-excalidraw.canvas.*` 标识，在思源能力列表中发现实际调用名称。模块停用时拒绝操作。旧版思源缺少能力 API 时普通画图仍可使用。

工具箱发布的思源 Skill 名称为 `dodo-toolbox-excalidraw`，避免接管原插件的同名 Skill。旧 `dodo-excalidraw` Skill 不自动删除，切换后可按需移除。禁用模块不会删除配置、素材库或画布。

回退时停用工具箱模块并启用原插件。切换后工具箱素材库的新增内容需显式导出，双方不自动同步。

开发验证：

```sh
pnpm build
pnpm test:excalidraw
python scripts/test-excalidraw-browser.py
pnpm test:excalidraw-toolbar
```

浏览器回归使用 Python Playwright 和 Chromium（优先使用本机 Chrome），文件 API 在隔离服务器内模拟，不修改真实思源文件。`pnpm dev` 同时监听宿主和 iframe 入口。

迁入代码来自 Yuxin Zhao 的 MIT 插件及其智能体画布扩展；原许可证和第三方声明位于 `licenses/`，随插件发布。

工具模块位于 `app/tools/`，各自导出 `ToolbarTool` 定义并在 `app/tools/index.ts` 中登记。工具只提供适用条件、执行方法或面板；宿主统一处理选区、定位、菜单、错误及配置。共享的 `app/scene-positions.ts` 负责一次性提交元素移动及绑定元素更新，保持思源版本号和撤销记录。交互模块实现 `InteractionFeature.mount(api)` 并返回清理函数，登记在同一文件的 `interactionFeatures` 中；停用及画布关闭会调用清理函数。配置由思源插件宿主统一保存并向画布广播，画布仅提交允许字段的差量更新。


### 原生思源块预览与原位编辑


思源块选中时在**自定义选区工具栏**统一显示 **编辑 / 刷新 / 编辑链接**；进入 Protyle 原位编辑后，原工具栏把编辑切换为 **完成**，并保留刷新、编辑链接。块右上角和宿主编辑层不再有独立浮动按钮。单击编辑器外部会结束编辑（思源自身弹出菜单除外）。选中思源块时仅隐藏原生链接查看栏，点击工具栏的编辑链接后隐藏自定义工具栏并显示原生 URL 输入框，保留块 ID 地址及 @ 搜索；右键连线支持思源嵌入块作为端点，普通 Web-Embed 不变。

**右键连线/删除（2026-11）**：参考旧版 right-drag-tools.js 恢复多选后一对多与多对一的右键连线：选中多个元素，从组内任意元素右拖至组外元素时生成多对一；从组外右拖至组内时生成一对多。普通单连线、拖向空白复制并连接、容器文字映射保持原逻辑。多条新箭头及其两端 boundElements 一次性写入，可整体撤销。右键扫线可以删除多元素及其关联箭头，但永远不对 frame/magicframe 画框执行预览或删除。

**大量思源块保存优化（2026-11）**：完整保存首先核对每个块的链接、内容 SHA-256 指纹、尺寸及刷新版本，源内容未变化时直接复用现有 PNG 快照，不再执行 SnapDOM，也不重复上传不变的快照缓存。移动、颜色、旋转、连线变化仍会更新整张静态图，但不会重复截图块内容。视口外首次截图使用只读 iframe，不会在保存期间改变画布版本。原有画布中 embedSiyuan 的 Markdown/DOM 正文副本加载时会迁移为 blockId+contentHash+config；实时预览仍向思源读取内容。20 个及以上嵌入块时，自动完整预览更新会等待停止编辑至少 20 秒，快速自动保存保持原来逻辑。控制台以 [dodo-excalidraw] snapshot capture、embed snapshots、full preview export、save completed 记录缓存命中与保存阶段耗时。首次升级/缓存迁移仍需生成完整快照，下一次才会明显加速；保存的原始可编辑数据和静态 SVG/PNG 预览保持分离。对于其他客户端修改的块，进入画布或手动刷新对应块后才会刷新其指纹和快照。

**保存后静态预览**：主动保存 SVG/PNG 时会重新绘制画布，并将思源块、Markdown 嵌入的可见 iframe 内容截图为透明 PNG，再嵌回静态图像。这样规避多层嵌套 SVG foreignObject 在思源预览中不显示文字的问题。截图前等待异步块 DOM 加载；对于视口外未挂载的 iframe 临时创建离屏副本。原始 scene metadata 永远保持块 ID/画布几何属性，不用截图覆盖编辑数据；单纯后台自动保存可以保留上次静态图，显式保存始终刷新。如截图或原始场景元数据不可得，保存会明确报错，不再写入看似成功的空白图片。

存储策略：可编辑画布主要保存 embeddable 元素的 link=siyuan://blocks/<blockID>、位置、尺寸、样式和绑定箭头，不保存思源原文副本；iframe 预览按 ID 从思源读取实时内容。为生成静态 SVG/PNG 导出，另有临时 iframe 截图缓存（/temp/siyuan-dodo/excalidraw/cache/），与画布引用数据分离，不应以导出截图作为可编辑内容来源。


思源块嵌入现为两层交互：**默认只读预览 → 编辑**。Excalidraw 不再出现「点击以开始交互」的中间激活提示或状态；选中思源块时自定义选区工具栏直接显示「编辑」「刷新」「编辑链接」，无需先激活 iframe。双击块也可以进入原位编辑；仍可在只读状态滚动较长的块内容。画布拖动、选中、缩放由 Excalidraw 负责，其他网页嵌入（Web-Embed）继续保持其原来的交互方式。


思源内嵌画布中的 `siyuan://blocks/块ID` 继续使用原有嵌入数据格式。 只读预览现在同步思源主题排版变量、原生 SVG 列表符号以及 `/api/outline/getDocHeadingNumbers` 生成的多级标题编号，减少预览与编辑的差异。平时按需获取块 DOM，并由宿主 `ProtyleMethod` 渲染代码高亮、公式、图表等特殊内容；无需为每个块挂载 Protyle。

双击嵌入内容或者点击其编辑图标：插件在画布对应位置创建一个使用思源宿主 App 的原生 Protyle（只保留一个活跃编辑实例）。编辑后按「完成」或 `Esc` 退出，实例销毁并按块 ID 刷新预览。若宿主未提供原生编辑能力，仍可退回原有悬浮窗。

注意：直接编辑在思源宿主中进行，而非无宿主的独立浏览器；当前需要在真实思源环境验证特殊块及数据库交互。Protyle 可能按思源内部加载规则显示目标块的上下文，现阶段不应将轻量预览或兼容性回退误认为完整原位编辑功能。


### 思维导图创建后自动编辑：体验试用关闭（2026-11）

在 src/lets-excalidraw/app/mindmap/actions.ts 中保留 editMindNodeText 和完整原生编辑逻辑，但将 AUTO_EDIT_NEW_MIND_NODE 临时设置为 false。创建中心主题、添加子节点、添加兄弟节点（包括 Tab/Enter 快捷键）时只创建并选中新节点，不再自动打开 WYSIWYG。双击节点仍可编辑，编辑结束后的文字尺寸自适应、导图布局、折叠、拖拽、拆分与合并均保持不变。若试用后希望恢复旧体验，只需把该开关改回 true。

### 初始化样式与本机持久化（2026-11）

- 在 Excalidraw「自定义工具栏 → 其他设置 → 绘图初始化样式」，点击「保存当前样式为初始化」。
- 初始化样式写入思源插件的同步配置 dodo-config / excalidraw.drawingInitialStyle，通过现有 settings.save() 持久化；是否能跨设备到达取决于思源工作空间同步配置。
- 初始化保存当前 Excalidraw 工具默认状态的描边色、背景色、线宽、线型、填充、手绘感、圆角、透明度、字体、字号、文本对齐及箭头端点。默认未配置时手绘感为 0、边角为尖锐（roundness: null）。
- 画布打开时只应用一次，修改的是当前绘图工具的 appState，不修改已有元素；保存预设后下次重开画布生效，当前画布不会被重置。
- 「其他设置 → 默认样式持久化」继续独立使用 localStorage 键 siyuan-embed-excalidraw.tool-state，默认不启用。启用后上次样式优先于同步初始化预设；关闭后重新打开画布使用同步初始化预设。
- 「自定义工具栏 → 重置」不会删除已保存的初始化预设；独立浏览器访问可以读取预设，但为了避免绕过主插件造成配置写入冲突，不允许从独立浏览器修改同步初始化值。


### Lucide 图标来源（2026-11）

图标浏览器新增 Lucide 来源（官方 ISC 授权，Iconify JSON 包），以独立动态导入的方式离线加载约 2095 个图标及 224 个兼容别名。沿用图标搜索、每批 80 项滚动加载、最近使用、颜色取色器、描边宽度调整、画布 SVG 文件插入与保存后重新编辑。图库仍按原有名称顺序保留 Tabler、IconPark、Phosphor、Carbon、DiceBear；保存到 dodoIcon 元数据的新 library 值为 lucide，旧画布兼容不变。

DiceBear 头像当前已支持 Open Peeps、Notionists、Pixel Art、Lorelei 和 Pixelbot 五种 CC0 风格，详情见下一节。

### DiceBear 新增四种离线头像风格（2026-11）

在「插入图标 → DiceBear 头像」中选择 Open Peeps、Notionists、Pixel Art、Lorelei、Pixelbot 风格；可浏览每种风格的 36 个预览，用种子生成可重复的个性化头像，插入为内嵌 SVG，保存后仍可以选择头像修改种子或切换风格并重新生成。

四种新风格使用独立的 DiceBear v10 核心与 JSON 素材动态模块（Notionists、Pixel Art、Lorelei、Pixelbot），各风格资源仅在选择时按需加载。已有 Open Peeps 继续用 DiceBear v9 生成，以确保旧画布不因新版算法变化而出现头像变化。新头像 dodoIcon.avatarStyle 记住具体风格；旧头像缺少此字段时按 Open Peeps 处理。「最近使用」按风格分别显示，旧本机记录自动归入 Open Peeps。以上五种风格在 DiceBear 官方均列为 CC0 1.0 素材；生成 SVG 包含在保存的画布中，重新打开不依赖网络服务。

### 图标库滚动自动加载（2026-11）

图标库将手动「加载更多（已显示 80 / ...）」按钮替换为结果滚动区中的 IntersectionObserver 哨兵；滚动接近底部时自动追加 80 个图标，避免一次渲染几千个预览。搜索、切换图标来源或风格、关闭后重新打开时从第一页开始；图标预览图片采用 loading=lazy、decoding=async。观察器只绑定图标结果滚动容器，不监听整个画布滚动，并会在弹窗关闭或筛选切换后解除监听。

### 左侧工具面板按钮并入原生顶栏（2026-11）

「其他设置」启用「左侧工具面板开关」时，按钮不再单独占据左上角菜单下方一行，而是作为原生 main-menu-trigger 紧邻右侧的 36×36 按钮，与原生菜单采用相同的 dropdown-menu-button 外观、hover/focus 状态。面板显隐及 localStorage 记忆逻辑保持原样。关闭此项增强后移除按钮及布局样式；如 Excalidraw 重新渲染左上角菜单，也会重新挂载到原生按钮右侧。
